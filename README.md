## Функція

`splitBill(amount, people, tipPercent)` рахує, скільки має заплатити одна людина, якщо рахунок ділять порівну і додають чайові.

- сума рахунку множиться на (1 + чайові / 100) і ділиться на кількість людей
- результат округлюється до копійок
- кількість людей має бути цілим числом від 1
- чайові від 0 до 30 відсотків
- сума не може бути відʼємною

При неправильних даних функція кидає помилку з поясненням.

| Вхід | Результат |
|---|---|
| 100, 4, 0 | 25 |
| 100, 3, 10 | 36.67 |
| 0, 2, 15 | 0 |
| 100, 0, 10 | помилка |
| 100, 2, 31 | помилка |
